# ranAudio Function Call v1.0

> 日期：2026-09-09  
> 范围：离线单轮 wav → MiniCPM5 XML FC。不换 Demo 级联、不上 Omni、不接 Gateway。  
> 架构：[architecture.md](./architecture.md)

---

## 1. 范围

- 单轮：一条 wav 一次 `generate`，输出 **只有** function call。
- 工具：与 Demo 相同的 22 个车机工具（见 [`eval_car_fc.py`](../ranAudio/eval_car_fc.py) 的 `TEST_TOOLS`）。
- 必填槽：`navigate_to.destination`、`set_volume.level`、`set_temperature.degrees`。没听到的键不要编造。
- 不包含：HTTP infer、Slave 执行、TTS、1s 全双工 listen/speak。

---

## 2. 输出格式

MiniCPM5 XML（[`format_tool_xml`](../ranAudio/tools.py)），不是 MiniCPM-o 的 `<tool_call>{json}</tool_call>`。

```xml
<function name="navigate_to"><param name="destination">家</param></function>
```

无参：

```xml
<function name="enable_bluetooth"></function>
```

运行时用 [`parse_tool_calls`](../ranAudio/tools.py) 得到 `{name, arguments}`。解析器也可读 JSON / Qwen XML，**训练标签只写 MiniCPM5 XML**。

系统提示：只输出 function call，不要寒暄、不要解释。

---

## 3. 训练配方

样本：[`data/car_audio.jsonl`](../data/car_audio.jsonl)，约 **2750** 行（`build_samples.py` 默认）。

| | Align | FC |
|--|-------|-----|
| 脚本 | `python -m ranAudio.train_align` | `python -m ranAudio.train_fc` |
| epoch | 2 | 4 |
| lr | 1e-4 | 2e-4 |
| 可训练 | projector | projector + LoRA（~10.6M） |
| 监督 | 中文转写 | XML tool call |

LoRA：`r=16`，`alpha=32`，`target_modules=q_proj,v_proj`。APM 全程冻结。FC 阶段加载 `runs/align/projector.pt`。

产物：`runs/align/projector.pt`；`runs/fc/adapter_final/` + `projector_final.pt`。

---

## 4. 评测

[`eval_car_fc.py`](../ranAudio/eval_car_fc.py)：每个工具一条 `{name}_000.wav`；`name` 与 `arguments` **都相等** 才 PASS。

本机结果：**22/22 PASS**（`tmp/minicpm5_car_fc_eval.json`）。

---

## 5. 已知限制

- 无 HTTP / Demo 集成；无 TTS；无全双工。
- Whisper 必须 pad 到 3000 mel 帧再 crop（见 [architecture.md](./architecture.md)）。
- `generate_text` 须 `skip_special_tokens=False`，否则 XML 标签被吃掉，评测会变成残缺文本（例如只剩 `name="enable_bluetooth">`）。
- 领域仍是车机固定 22 工具 + 现有 wav；未测开放域。

---

## 6. 相对 MiniCPM-o 双工 v1.1

双工理想形态是口头确认（带槽）再出 `<tool_call>` JSON。ranAudio v1.0 **只出 FC、不出口头 ack**，从而避开 duplex「ack 后 turn_eos、不出 tool_call」的失败模式。

参数权威仍是解析后的 `name` + `arguments`。接 Slave 时不要让 Qwen XML 覆盖。版本号与 [`docs/function_call/v1.1.md`](../../MiniCPM-o-Demo/docs/function_call/v1.1.md) **无关**。
