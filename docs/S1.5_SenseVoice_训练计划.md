# S1.5 训练计划：冻结 2B，训 SenseVoice encoder + 新 projector

**状态**：S1.5a / S1.5b-S 已完成（均过出门线）· 下一步 **S1.5b-MS** · **日期**：2026-09-13  
**对应**：架构定义 §10.3 / §10.5；Encoder 槽位 = SenseVoice-Small  
**本阶段结束时的预期**：模型「只会转写」。这是设计目标，不是缺陷。S2 才解锁 `<|FC|>` / `<|NOFC|>`（见 [S2_FC_NOFC_训练计划.md](./S2_FC_NOFC_训练计划.md)）。Wenet 标签 **不加** 路由 token。

实测数字与例子见 **§9**。

---

## 1. 这一阶段在解决什么

转写能力必须沉淀在 **encoder + projector**，不能写进 2B。否则 S2 的 `<asr>` 会和 `<reply>` 抢同一批可写参数（§10.5）。

SenseVoice-Small 已经是中文 ASR encoder（512-d），**不需要从零对齐声学**。缺口是：

| 件 | 现状 |
|---|---|
| SenseVoice encoder | 预训练就绪，fp32，输出 512 |
| Projector | **随机初始化**，512 → 2048（两层 Linear） |
| MiniCPM5-2B | 冻结，连 LoRA 都不开 |
| 旧 `runs/align/projector.pt` | Whisper 1024-d，**禁止加载** |

因此不能一上来就用 `1e-4` 同时猛训整网 encoder。随机 projector 还在出垃圾梯度时，会把预训练声学冲掉。

---

## 2. 冻结与可写参数

| 模块 | S1.5a（projector 先对齐） | S1.5b（encoder 微调） |
|---|---|---|
| MiniCPM5-2B | 冻，`eval()`，无 LoRA | 同左 |
| SenseVoice encoder + query embed | 冻 | 解冻，lr = **1e-5** |
| Projector | 训，lr = **1e-4** | 继续训，lr = **1e-4** |

监督：`ASR_SYSTEM = "请把用户语音转成中文文本，只输出转写。"`  
标签 = 纯转写文本。**不要** `<mode>` / `<asr>` / `<reply>` / `<|FC|>` / `<|NOFC|>`。  
Loss 只打在 assistant token 上（现有 `teacher_force_batch`）。

Frontend（80-mel + LFR 7/6、`woitn` query）不训练。Wenet 文本本身接近无 ITN，和 `woitn` 一致。

## 3. 数据

来源：`/cmy/cmy/real-asr/data/manifests/wenetspeech/` 的 Lhotse 清单，按 `start/duration` 裁 opus。  
**不**读 Zipformer fbank。音频根：`/cmy/cmy/WenetSpeech/...`。

| 阶 | 清单 | 子集 | 规模（约） | 用途 |
|---|---|---|---|---|
| 冒烟 | `train_ms` | S | 64–256 条 | 梯度 / loss / 形状 |
| S1.5a | `train_ms` | S | ~100 h | 只训 projector |
| S1.5b-S | 同上 | S | 再过 1 epoch | 解冻 encoder |
| S1.5b-MS | `train_ms` | 全部 | ~1.51M / ~1000 h | 主对齐 |
| L（可选） | `train` | L | ~10000 h | 仅当 MS 后 CER 仍差且未过拟合 |

过滤（训练与导出都做）：

- 时长 **0.5–16 s**（2B 前向长度随音频帧线性涨；SenseVoice 约 60 ms/帧）
- 文本非空；过短 wav（`<1600` sample）跳过
- 流式读 jsonl + `.offsets.npy`，不把 151 万行装进内存

导出：

```bash
$PY -m ranAudio.prepare_wenet --split wenet-ms --subset S --index \
    --out data/wenet_s.jsonl
$PY -m ranAudio.prepare_wenet --split wenet-ms --subset all --index \
    --out data/wenet_ms.jsonl
```

评测集（训练中途与收官都跑）：

| 集 | 作用 |
|---|---|
| AISHELL `test` | 干净中文，主 CER |
| WenetSpeech `test_net` | 网上语音，泛化 |
| WenetSpeech `dev` | 选 ckpt，不调参到 test |
| 车机 22 条 | 实体 / 数字保真（`entity_fidelity`） |

`eval_asr` 默认最多 200 条；收官把 AISHELL / test_net 跑满。

## 4. 阶段、配方、出门门槛

当前 `train_s15_asr.py` 是单条循环、单一 lr、只按 epoch 存盘。  
**冒烟可以先用它**；S / MS 正式跑之前要把 §5 的缺口补上。

### 4.0 冒烟（必须先过）

- 64 条 S，batch=1，确认：
  - `encode_wav` → `[T, 512]`，projector → `[T, 2048]`
  - `2B.grad is None`；encoder 在 1.5a 也无梯度
  - 随机 projector 的 AISHELL CER ≈ 乱码 / ~1.0（对照）
  - 几十 step 后 teacher-force loss 下降
- 不过：停，查模板 / pad 对齐 / 旧权重误载，不要加数据。

### 4.1 S1.5a — 冻 encoder，只训 projector

| 项 | 值 |
|---|---|
| 数据 | Wenet S，0.5–16 s |
| epoch | 1（约 100 h，过一遍） |
| lr | projector `1e-4`，encoder 冻 |
| 优化 | AdamW，grad clip 1.0 |
| 存盘 | `runs/s15_asr/a/` 每 2k step + epoch 末 |

**出门**：AISHELL-test 抽检 CER **< 0.25**，且明显低于随机对照。  
**结果（2026-09-12）**：过了。loss 13→0.9；训练中途 AISHELL 前 50 条最好 CER **0.193**（step 148000）。权重：`runs/s15_asr/a/projector_best.pt`。详见 §9。

### 4.2 S1.5b-S — 解冻 encoder，小 lr

从 `a/` 最好的 projector 接着训。

| 项 | 值 |
|---|---|
| 数据 | 同一份 S |
| epoch | 1 |
| lr | encoder `1e-5`，projector `1e-4` |
| 存盘 | `runs/s15_asr/b_s/` |

**出门**：AISHELL CER **< 0.15**；车机 22 能认出部分实体（不要求 22/22）。  
encoder CER 相对 a **变差**：立刻降 encoder lr 到 `3e-6` 或退回 a 的权重。  
**结果（2026-09-12）**：过了。AISHELL 前 50 条最好 CER **0.0828**（step 128007），收官 0.0978。权重：`runs/s15_asr/b_s/projector_best.pt` + `encoder_best.pt`。详见 §9.3。车机 22 / 全量 AISHELL / test_net **未跑**。

### 4.3 S1.5b-MS — 主对齐

| 项 | 值 |
|---|---|
| 数据 | `wenet_ms.jsonl`，同样时长过滤 |
| epoch | 1（约 1.51M；中途按 CER 早停） |
| lr | 同 4.2，可选 cosine，5% warmup |
| 存盘 | `runs/s15_asr/` 每 5k step；保留 CER 最好的一份 |

**收官门槛（进 S2 的最低线）**：

| 指标 | 目标 |
|---|---|
| AISHELL-test CER | **< 0.08** |
| test_net CER | **< 0.20**（网上语音，允许更高） |
| 车机 22 CER | 记录；`entity_fidelity` 不掉到 0 |
| 转写脑补 | hyp 里不应稳定出现 ref 没有的专名 / 数字「纠正」 |

达不到：先加 MS 的第二个半 epoch，或只再训 projector。  
**不要**为此解冻 2B。  
L 子集只在 MS 已过门槛、还想压 test_net 时再开。

SenseVoice 自带 CTC 在 AISHELL 上大约 2–3% CER。经过冻结 2B 解码，**不要按这个数当 S1.5 目标**。本阶段要的是「2B 能稳定读 SenseVoice 帧」，不是替换 SenseVoice 官方解码器。

### 4.4 明确不做

- 不写 `<mode:speak|route>` / `<|FC|>` / `<|NOFC|>`（那是 S2）
- 不训 TTS / AEC / 流式 chunk-causal（S1）
- 不上 encoder 侧 CTC 辅助 head（OPEN-7，非主路径）
- 不混闲聊 / 工具 / 纯文本 batch
- 不加载 `runs/align/`、`runs/fc/` 的 Whisper 权重

## 6. 建议命令（补完 §5 之后）

```bash
# 0) 导出 S
$PY -m ranAudio.prepare_wenet --split wenet-ms --subset S --index

# 1) 冒烟
$PY -m ranAudio.train_s15_asr --prepare-s --max-samples 64 --out-dir runs/s15_asr/smoke

# 2) S1.5a
$PY -m ranAudio.train_s15_asr --samples data/wenet_s.jsonl \
    --freeze-encoder --lr 1e-4 --out-dir runs/s15_asr/a
$PY -m ranAudio.eval_asr --split aishell-test --also-car \
    --projector runs/s15_asr/a/projector_best.pt --encoder ""

# 3) S1.5b-S（当前下一步）
$PY -m ranAudio.train_s15_asr --samples data/wenet_s.jsonl \
    --projector runs/s15_asr/a/projector_best.pt \
    --encoder-lr 1e-5 --lr 1e-4 --out-dir runs/s15_asr/b_s
$PY -m ranAudio.eval_asr --split aishell-test --also-car \
    --projector runs/s15_asr/b_s/projector.pt \
    --encoder runs/s15_asr/b_s/encoder.pt

# 4) S1.5b-MS（过 4.2 门槛再开）
$PY -m ranAudio.prepare_wenet --split wenet-ms --subset all --index \
    --out data/wenet_ms.jsonl
$PY -m ranAudio.train_s15_asr --samples data/wenet_ms.jsonl \
    --projector runs/s15_asr/b_s/projector.pt \
    --encoder runs/s15_asr/b_s/encoder.pt \
    --encoder-lr 1e-5 --lr 1e-4 --out-dir runs/s15_asr
$PY -m ranAudio.eval_asr --split aishell-test --max-samples 0
$PY -m ranAudio.eval_asr --split wenet-test_net --max-samples 0
```

产物约定：S2 只读 `runs/s15_asr/encoder.pt` + `projector.pt`（MS 上 CER 最好的那份）。

## 7. 监控（训练中看这三件事）

| 信号 | 正常 | 停 / 退步 |
|---|---|---|
| teacher-force loss | 平稳下降 | 长时间不降，或 1.5b 相对 1.5a 暴涨 |
| AISHELL CER | a → b-S → MS 递减 | 解冻 encoder 后回升（lr 过大） |
| 转写脑补 | 错成近音 / 删除 | 稳定「纠正」数字、地名（2B 先验漏进来；查是否冻住） |

S1.5 **不管** 上派率、复读率、文本 FC。那些是 S2 / 基线的事。本阶段结束时 2B 被 prompt 成「只转写」，闲聊能力看起来消失是预期。

## 8. 时间量级（单卡、batch=1、accum=8）

粗估，以 opus 裁剪 + 2B 前向为主：

| 阶 | 量级 |
|---|---|
| 冒烟 64 | 分钟级 |
| S 1 epoch（a 或 b） | 大约半天到 1 天 |
| MS 1 epoch | 数天；必须靠中途 CER 早停，不要盲跑满 |

精确 wall-clock 用冒烟 64 条的 step/s 外推。S1.5a 实测：**151528 step / 5.9 h**（~7 条/秒）。

## 9. S1.5a 实测（2026-09-12）

配方：冻 SenseVoice + 2B；随机初始化 `Linear(512→2048)→ReLU→Linear(2048→2048)`；Wenet S 151598 条，0.5–16 s；`lr=1e-4`，accum=8。H800，batch=1。

| 项 | 结果 |
|---|---|
| 步数 / 耗时 | 151528 step，约 5.9 小时 |
| teacher-force loss | 13 → **~0.9** |
| 训练中途 AISHELL test **前 50 条** 最好 CER | **0.193**（step 148000） |
| 收官同一 50 条 | 0.207 |
| 出门线（< 0.25） | **过了** |
| 抽检 AISHELL 前 8 条（`eval_asr`，`max_new_tokens=256`） | **0.225** |
| 车机 22 条 | 短指令多数 CER=0；数字 / 实体仍错 |

权重：`runs/s15_asr/a/projector_best.pt`（选 ckpt 用的是 50 条抽检，不是全量 7176）。  
原始逐条：`tmp/s15a_aishell8.json`。  
**未跑**：AISHELL 全量、Wenet `test_net`、`dev`。

### 9.1 评测怎么做的

中途：每 2000 step，`generate_text` greedy，system=`请把用户语音转成中文文本，只输出转写。`，最多 64 新 token。  
CER：去空白后字级编辑距离 / 参考长度，再对样本取平均。

### 9.2 具体例子（`projector_best.pt`）

AISHELL test 前 8 条：

| BAC009S0764W0122 | 一二线城市虽然也处于调整中 | 一二级城市区仍然处于调整中 | 0.308 |

### 9.3 S1.5b-S 实测（2026-09-12）

配方：从 `a/projector_best.pt` 接着训；解冻 SenseVoice `1e-5`，projector `1e-4`；时长 batch ~32 s，`num_workers=4`，accum=1。H800，约 **1.67 h**。日志：`runs/s15_asr/b_s/train.log`。

| 项 | 结果 |
|---|---|
| 步数 / 耗时 | 151404 utt / 11829 opt step，约 1.67 小时 |
| 训练中途 AISHELL test **前 50 条** 最好 CER | **0.0828**（step 128007） |
| 收官同一 50 条 | 0.0978 |
| 出门线（< 0.15，且不差于 0.193） | **过了** |

**未跑**：AISHELL 全量、Wenet `test_net`、`dev`、车机 22。
