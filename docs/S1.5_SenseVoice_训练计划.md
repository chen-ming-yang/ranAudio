# S1.5 训练计划：冻结 2B，训 SenseVoice encoder + 新 projector

**状态**：S1.5a / S1.5b-S / **S1.5b-MS 已完成**（进 S2 门槛已过）· 下一步 **S2** · **日期**：2026-09-19  
**对应**：架构定义 §10.3 / §10.5；Encoder 槽位 = SenseVoice-Small  
**本阶段结束时的预期**：模型「只会转写」。这是设计目标，不是缺陷。S2 才解锁 `<|FC|>` / `<|NOFC|>`（见 [S2_FC_NOFC_训练计划.md](./S2_FC_NOFC_训练计划.md)）。Wenet 标签 **不加** 路由 token。

实测数字与例子见 **§9**。

---

## 1. 这一阶段在解决什么

转写能力必须沉淀在 **encoder + projector**，不能写进 2B。否则 S2 的 BASE 后转写会和 NOFC 正文抢同一批可写参数（§10.5）。

SenseVoice-Small 已经是中文 ASR encoder（512-d），**不需要从零对齐声学**。缺口是：

| 件 | 现状 |
|---|---|
| SenseVoice encoder | 预训练就绪，fp32，输出 512 |
| Projector | **随机初始化**，512 → 2048（两层 Linear） |
| MiniCPM5-2B | 冻结，连 LoRA 都不开 |
| 旧 `runs/align/projector.pt` | Whisper 1024-d，**禁止加载** |

因此不能一上来就用 `1e-4` 同时猛训整网 encoder。随机 projector 还在出垃圾梯度时，会把预训练声学冲掉。

## 2. 冻结与可写参数

| 模块 | S1.5a（projector 先对齐） | S1.5b（encoder 微调） |
|---|---|---|
| MiniCPM5-2B | 冻，`eval()`，无 LoRA | 同左 |
| SenseVoice encoder + query embed | 冻 | 解冻，lr = **1e-5** |
| Projector | 训，lr = **1e-4** | 继续训，lr = **1e-4** |

监督：`ASR_SYSTEM = "请把用户语音转成中文文本，只输出转写。"`  
标签 = 纯转写文本。**不要** `<|FC|>` / `<|NOFC|>`（那是 S2）。  
Loss 只打在 assistant token 上（现有 `teacher_force_batch`）。

Frontend（80-mel + LFR 7/6、`woitn` query）不训练。Wenet 文本本身接近无 ITN，和 `woitn` 一致。

## 4. 阶段、配方、出门门槛

当前 `train_s15_asr.py` 是单条循环、单一 lr、只按 epoch 存盘。  
**冒烟可以先用它**；S / MS 正式跑之前要把 §5 的缺口补上。

### 4.0 冒烟（必须先过）

- 64 条 S，batch=1，确认：
  - `encode_wav` → `[T, 512]`，projector → `[T, 2048]`
  - `2B.grad is None`；encoder 在 1.5a 也无梯度
  - 随机 projector 的 AISHELL CER ≈ 乱码 / ~1.0（对照）
  - 几十 step 后 teacher-force loss 下降
- 不过：停，查模板 / pad 对齐 / 旧权重误载，不要加数据。

### 4.1 S1.5a — 冻 encoder，只训 projector

| 项 | 值 |
|---|---|
| 数据 | Wenet S，0.5–16 s |
| epoch | 1（约 100 h，过一遍） |
| lr | projector `1e-4`，encoder 冻 |
| 优化 | AdamW，grad clip 1.0 |
| 存盘 | `runs/s15_asr/a/` 每 2k step + epoch 末 |

**出门**：AISHELL-test 抽检 CER **< 0.25**，且明显低于随机对照。  
**结果（2026-09-12）**：过了。loss 13→0.9；训练中途 AISHELL 前 50 条最好 CER **0.193**（step 148000）。权重：`runs/s15_asr/a/projector_best.pt`。详见 §9。

### 4.2 S1.5b-S — 解冻 encoder，小 lr

从 `a/` 最好的 projector 接着训。

| 项 | 值 |
|---|---|
| 数据 | 同一份 S |
| epoch | 1 |
| lr | encoder `1e-5`，projector `1e-4` |
| 存盘 | `runs/s15_asr/b_s/` |

**出门**：AISHELL CER **< 0.15**；车机 22 能认出部分实体（不要求 22/22）。  
encoder CER 相对 a **变差**：立刻降 encoder lr 到 `3e-6` 或退回 a 的权重。  
**结果（2026-09-12）**：过了。AISHELL 前 50 条最好 CER **0.0828**（step 128007），收官 0.0978。权重：`runs/s15_asr/b_s/projector_best.pt` + `encoder_best.pt`。详见 §9.3。全量 AISHELL / test_net / 车机 22 在 MS 收官后补跑，见 §9.5。

### 4.3 S1.5b-MS — 主对齐

| 项 | 值 |
|---|---|
| 数据 | `wenet_ms.jsonl`，同样时长过滤 |
| epoch | 1（约 1.51M；中途按 CER 早停） |
| lr | 同 4.2，可选 cosine，5% warmup |
| 存盘 | 实际写到 `runs/s15_asr/b_ms/`，续训 `b_ms_cont/`；每 5k step，保留 CER 最好 5 份 |

**结果（2026-09-16/17）**：过了。续训 1 epoch 后 AISHELL 前 50 条最好 **0.0316**（step 635010）。全量收官见 §9.4 / §9.5。S2 只读 `b_ms_cont` 这对 best。

**收官门槛（进 S2 的最低线）**：

| 指标 | 目标 |
|---|---|
| AISHELL-test CER | **< 0.08** |
| test_net CER | **< 0.20**（网上语音，允许更高） |
| 车机 22 CER | 记录；`entity_fidelity` 不掉到 0 |
| 转写脑补 | hyp 里不应稳定出现 ref 没有的专名 / 数字「纠正」 |

达不到：先加 MS 的第二个半 epoch，或只再训 projector。  
**不要**为此解冻 2B。  
L 子集只在 MS 已过门槛、还想压 test_net 时再开。

SenseVoice 自带 CTC 在 AISHELL 上大约 2–3% CER。经过冻结 2B 解码，**不要按这个数当 S1.5 目标**。本阶段要的是「2B 能稳定读 SenseVoice 帧」，不是替换 SenseVoice 官方解码器。

### 4.4 明确不做

- 不写 `<|FC|>` / `<|NOFC|>`（那是 S2）
- 不训 TTS / AEC / 流式 chunk-causal（S1）
- 不上 encoder 侧 CTC 辅助 head（OPEN-7，非主路径）
- 不混闲聊 / 工具 / 纯文本 batch
- 不加载 `runs/align/`、`runs/fc/` 的 Whisper 权重

配方：冻 SenseVoice + 2B；随机初始化 `Linear(512→2048)→ReLU→Linear(2048→2048)`；Wenet S 151598 条，0.5–16 s；`lr=1e-4`，accum=8。H800，batch=1。

| 项 | 结果 |
|---|---|
| 步数 / 耗时 | 151528 step，约 5.9 小时 |
| teacher-force loss | 13 → **~0.9** |
| 训练中途 AISHELL test **前 50 条** 最好 CER | **0.193**（step 148000） |
| 收官同一 50 条 | 0.207 |
| 出门线（< 0.25） | **过了** |
| 抽检 AISHELL 前 8 条（`eval_asr`，`max_new_tokens=256`） | **0.225** |
| 车机 22 条 | 短指令多数 CER=0；数字 / 实体仍错 |

**未跑**：AISHELL 全量、Wenet `test_net`、`dev`。

### 9.1 评测怎么做的

中途：每 2000 step，`generate_text` greedy，system=`请把用户语音转成中文文本，只输出转写。`，最多 64 新 token。  
CER：去空白后字级编辑距离 / 参考长度，再对样本取平均。

### 9.4 S1.5b-MS 实测（2026-09-13 → 09-17）

配方：从 `b_s` best 接着训 `data/wenet_ms.jsonl`（约 151 万条 / ~1000 h，0.5–16 s）；encoder `1e-5`，projector `1e-4`；时长 batch ~32 s。H800。

### 9.5 主链路收官评测（`b_ms_cont` best，2026-09-18/19）

`eval_asr`，`generate_text` greedy，system 同训练，`max_new_tokens=256`（中途抽检是 64）。  
**句均 CER**：每句编辑距离 / 参考长度再平均（和训练中途一致）。  
**整库 CER**：全库编辑次数 / 全库参考字数。字切分：只去空白。

| WenetSpeech `test_net` 全量 | 24774 | **0.1585** | **0.1273**（52920/415747） | < 0.20 | **过** |
| 车机 22 | 22 | **0.0346** | **0.0526**（5/95） | 记录 | 20/22 全对 |

- AISHELL：`tmp/s15_b_ms_cont_aishell_full.json`

### 9.6 构音障碍旁路（不影响主链路，2026-09-18/19）

独立目录，**只读** `b_ms_cont` best 热启，不写回 `b_ms_cont`，不改 `infer.py` / S2 入口。
