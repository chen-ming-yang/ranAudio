# ranAudio Function Call v1.1（判官）

> 日期：2026-09-10  
> 范围：MiniCPM5-2B 输出 **ASR + need_fc**；`need_fc=false` 时 2B **自己当普通 LLM 写 reply**；`need_fc=true` 时只出 ASR，交给下游 Qwen Slave 规划执行。  
> 不覆盖 [v1.0.md](./v1.0.md)。架构：[architecture.md](./architecture.md)

---

## 1. 相对 v1.0 改了什么

| | v1.0 | v1.1 |
|--|------|------|
| 2B 职责 | 直接出 MiniCPM5 XML 工具调用 | 判是否需要 FC；无 FC 时自己回复 |
| 槽位 / 工具名 | 2B 填写 | 仅当 `need_fc=true`：下游 Qwen 从 ASR 规划 |
| 负样本 | 几乎全是车机指令 | **必须有** 闲聊（带 `reply` 标签） |
| Slave | 不调用 | **仅** `need_fc=true` 时异步规划执行 |

拍板：

- **`need_fc=false`**：2B 作为正常 LLM，输出 `asr` + `need_fc` + `reply`；**不**再把 ASR 交给 Slave 做对话。
- **`need_fc=true`**：2B **只**出 `asr` + `need_fc`（不要 `reply`）；ASR 交给 Qwen Slave `:22600` 自由规划并执行 ToolRegistry。

## 2. 2B 输出契约

同一次 `generate` 只出一行 JSON：

```json
{"asr": "导航去家", "need_fc": true}
{"asr": "今天天气怎么样", "need_fc": false, "reply": "我这边看不到实时天气，建议你看一下手机天气应用。"}
```

- `asr`：听到的中文转写。
- `need_fc`：车机控制意图为 `true`，闲聊 / QA 为 `false`。
- `reply`：**仅** `need_fc=false` 时必填；`true` 时不要填。
- 2B **不**输出 `name` / `arguments` / `<function>`。

格式与解析：[`tools.py`](../ranAudio/tools.py) 的 `format_judge_json` / `parse_judge`。  
系统提示：`judge_system_prompt()`。推理 **不传** `tools=`。

## 3. 下游路由

```text
wav → 2B → {asr, need_fc, reply?}
  ├─ need_fc=true  → Slave POST /v1/chat/completions
  │                  user=asr, tools=22, tool_choice 自由, execute_tools=true
  └─ need_fc=false → 直接返回 2B 的 reply（不调用 Slave）
```

编排：[`downstream.py`](../ranAudio/downstream.py) / [`infer.py`](../ranAudio/infer.py)。不进 Gateway / `py_backend`。

缺必填槽仍由 Registry 失败，禁止静默默认。

- 正例：车机 wav，`need_fc=true`，`asr=text`，无 `reply`（[`build_judge_samples.py`](../ranAudio/build_judge_samples.py)）。

- v1.0 的 `train_fc.py` / `runs/fc/` **保留不动** 作基线。
- **当前未要求开训**；先以本契约改代码与文档为准。

## 5. 评测

[`eval_judge.py`](../ranAudio/eval_judge.py)：

- `need_fc` 必须正确。
- `asr` 与标签完全一致（规范化空白后）。
- `need_fc=false`：`reply` 非空才算 PASS（不要求和模板逐字相同）。
- 正例：22 工具 `_000.wav`；负例：chat wav 子集。

下游 FC 对错不计入 2B 分数。

---

## 6. 已知限制

- 2B 不再保证 v1.0 的 XML 22/22；两套权重并存。
- Slave 自由规划质量取决于 Qwen。
- 负例 `reply` 目前多为模板句，后续可换成更高质量对话标注。
