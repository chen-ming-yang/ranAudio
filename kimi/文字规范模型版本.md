v3 的推理指令和训练指令是同一句：

> 下面是语音识别原文。若句中用组词或偏旁说明字形，把被说明的字和说明本身改成同一个正确字。若用「第N条」「第N点」或「下一条」逐条列举，收成从 1. 开始、每条一行的编号。若在报菜名或罗列一串名称，每个名称单独一行，不加序号。没有这类情况则原样输出。只输出全文。

训练集里都不出现「陈名扬」这四个字。

## v0：零样本

2026-10-24。关闭 thinking，贪心解码。Prompt 里不放字表。

| 模型 | 条件 | 结果 |
|---|---|---|
| Qwen3.5-2B | 只有别的拆字例子 | 原句原样返回 |
| Qwen3.5-2B | prompt 里写入「陈明阳 → 陈名扬」 | 姓名变成「陈名阳」，说明变成「扬」，前后不一致 |
| Qwen3.5-9B | 只有别的例子 | 只改成「陈明扬」，「名」没改出来 |
| Qwen3.5-9B | prompt 里写入这句的标准答案 | 换姓可以套一部分；「杨是提手旁的杨」「铁手旁的羊」仍不对 |

结论：汉字和偏旁补不进 prompt，需要用合成数据微调 2B。

## v1：单字修改

2026-10-24 训完。每句只改一个字。比例是组词 40%、偏旁 30%、已经正确 15%、普通句 15%。竹字头、走之底、工字旁、穴字头故意不进训练集。

训练：2 epoch，batch 32，grad accum 1，lr 2e-4，LoRA r=16、alpha=32。训练损失 0.0168，验证损失 0.0353。

贪心验证 **391/400（97.8%）**。必须原样的两句是对的：

- 「我是李小明，明是明日的明」保持不变
- 「今天天气不错，适合出门散步。」保持不变

三句目标姓名没有改对：

| 原文 | 模型输出 |
|---|---|
| 我叫陈明阳，明是名字的明，阳是提手旁的阳。 | 我叫陈明扬，扬是名字的扬，扬是提手旁的扬。 |
| 我叫陈明阳，名是名字的名，杨是提手旁的杨。 | 我叫陈明扬，名是名字的手，扬是提手旁的扬。 |
| 我是陈名杨，名是名字的名，杨是铁手旁的羊 | 我是陈名扬，扬是名字的扬，扬是提手旁的扬 |

另外 6 条失败是留出的偏旁，模型把原文原样返回。提手旁到「扬」已经学会，「明」和「名字」对不齐，一句里的两处说明会串到后一个字上。

这一版没有接到识别服务。

## v2：一句两处说明

2026-10-24。仍是 Qwen3.5-2B LoRA，同一套超参。训练损失 0.0236，验证损失 0.0026。数据仍是 8000 训练 / 400 验证，训练集不含「陈名扬」。

相对 v1 只改了数据：

- 组词单改 28%，偏旁单改 20%
- 一句里两处都改 10%
- 一句里一处保持、一处修改 12%（含「明是明日的明」保持，另一个字才改）
- 已经正确 15%，普通句 15%
- 竹字头、走之底、工字旁、穴字头放进训练集
- 名字里的字和说明里的字可以是不同的同音字

贪心验证 **400/400**。五句门槛：

| 原文 | 输出 |
|---|---|
| 我叫陈明阳，明是名字的明，阳是提手旁的阳。 | 我叫陈名扬，名是名字的名，扬是提手旁的扬。 |
| 我叫陈明阳，名是名字的名，杨是提手旁的杨。 | 我叫陈名扬，名是名字的名，扬是提手旁的扬。 |
| 我是陈名杨，名是名字的名，杨是铁手旁的羊 | 我是陈名扬，名是名字的名，扬是提手旁的扬 |
| 我是李小明，明是明日的明 | 原样 |
| 今天天气不错，适合出门散步。 | 原样 |

### 接入与时延（2026-10-24）

接到 [`scripts/l1_server.py`](scripts/l1_server.py)。Qwen3-ASR-1.7B 先发 final，再把全文送进 v2。partial 不跑这个模型。页面收到 `postprocess` 后替换主文本。失败时保留 final。

服务：`http://0.0.0.0:7864`，`--llm-postprocess` 默认开。适配器由 `qwen3-compare` 子进程加载，避免和 vLLM 的 transformers 抢同一套包。

时延是预热之后的贪心解码，每句 5 次，下面是中位数。这是 final 之后多出来的时间，不含识别本身。当前环境没有 flash-linear-attention，走较慢的 torch 实现。

| 原文 | 中位数 | 五次范围 | 输出是否正确 |
|---|---|---|---|
| 我叫陈明阳，明是名字的明，阳是提手旁的阳。 | 745 ms | 734–793 ms | 是 |
| 我叫陈明阳，名是名字的名，杨是提手旁的杨。 | 738 ms | 717–745 ms | 是 |
| 我是陈名杨，名是名字的名，杨是铁手旁的羊 | 614 ms | 602–627 ms | 是 |
| 我是李小明，明是明日的明 | 463 ms | 448–474 ms | 是，原样 |
| 今天天气不错，适合出门散步。 | 441 ms | 432–461 ms | 是，原样 |

25 次合在一起：中位数 **614 ms**，最小 432 ms，最大 793 ms。短句在已启动的服务上测过一条链路，final 之后约 218 ms，文本保持原样。

同一条服务上再把两段接起来测。语音按真实速度送进 Qwen3-ASR，时钟从最后一个采样点开始，到 `postprocess` 到达结束。第一句刚起来时识别收尾要 5.8 s，合计 6.5 s，这是冷启动。后面按真实语速重复，识别收尾大约 100–180 ms，文字规范仍是大头。

| 说出的句子 | 音频时长 | 识别收尾 | 文字规范 | 合计 |
|---|---|---|---|---|
| 我叫陈明阳，明是名字的明，阳是提手旁的阳。 | 5.2 s | 100 / 179 ms | 743 / 851 ms | 842 / 1030 ms |
| 我叫陈明阳，名是名字的名，杨是提手旁的杨。 | 5.6 s | 116 / 148 ms | 706 / 711 ms | 827 / 854 ms |
| 我是陈名杨，名是名字的名，杨是铁手旁的羊 | 5.8 s | 100 / 160 ms | 766 / 951 ms | 867 / 1110 ms |
| 我是李小明，明是明日的明 | 4.1 s | 134 / 161 ms | 521 / 598 ms | 654 / 759 ms |
| 今天天气不错，适合出门散步。 | 3.6 s | 134 / 146 ms | 428 / 432 ms | 566 / 575 ms |

这 10 次合计的中位数是 **848 ms**。名字这三句的合计在 827–1110 ms。识别结果里第三句被听成「我是陈明阳，明是名字的明，阳是铁手旁的阳。」，规范后仍是「我是陈名扬，名是名字的名，扬是提手旁的扬。」另外两句名字和两条原样句，识别与规范后都和目标一致。

## v3：编号列表和报菜名（当前）

2026-10-24。仍是 Qwen3.5-2B LoRA，同一套超参。训练损失 0.0192，验证损失 0.0021，650 step，约 9 分 34 秒。适配器 `sft_out/qwen35_2b_lora_v3`，v2 适配器保留。

数据 `eval_name_clarify/sft_v3`：v2 的 8000 条训练句只改了指令，标签不动；另加编号列表 1000、名称分行 1000、不该拆开的反例 400。训练集 10400 条，仍不含「陈名扬」。验证集 505 条，开头是组词五句，接着是列表五句。

编号列表收成每条一行的 `1.` `2.` `3.`，「下一条」接着往下数。报菜名、购物、名单每个名称一行，不加序号。普通逗号句和「合同第一条」保持原样。

贪心验证 **505/505**。换行算进对错，没有把空格和换行抹掉再比。十句门槛都过了：

| 原文 | 输出 |
|---|---|
| 我叫陈明阳，明是名字的明，阳是提手旁的阳。 | 我叫陈名扬，名是名字的名，扬是提手旁的扬。 |
| 我叫陈明阳，名是名字的名，杨是提手旁的杨。 | 我叫陈名扬，名是名字的名，扬是提手旁的扬。 |
| 我是陈名杨，名是名字的名，杨是铁手旁的羊 | 我是陈名扬，名是名字的名，扬是提手旁的扬 |
| 我是李小明，明是明日的明 | 原样 |
| 今天天气不错，适合出门散步。 | 原样 |
| 第一条买牛奶，第二条回家，下一条休息 | 1. 买牛奶 / 2. 回家 / 3. 休息，各占一行 |
| 帮我记一下，第一点开会，下一条写报告 | 帮我记一下，然后 1. 开会 / 2. 写报告 |

训练时停过 7864 上的识别服务。验证通过后已用 v3 适配器重新拉起，partial 仍然不改。这一版还没有重测时延，flash-linear-attention 也还没装上。

## 下一版怎么加

新的文字规范继续补进同一份数据，和 v3 的旧句一起再训。不为每种规范单独挂适配器，也不把例子写进 prompt。语音修改指令仍然另做。
